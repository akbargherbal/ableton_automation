# Archived teaching materials

These files belong to the project's **previous** teaching/tutoring orientation
(the "Ableton Live 12 AI Tutor & UI Grounding Suite" and the "Mastering Suno AI
Music" course). The project pivoted to **automation** — see `ROADMAP.md`,
`docs/CHANNEL_MATRIX.md`, and `AUTOMATION_AGENT_POLICY.md` at the repo root.

They are kept for reference because the click-automation engine they describe is
still the UIA layer used by the automation driver. They are no longer the
project's operating policy.

| File | Was |
|---|---|
| `course_outline.txt`, `curriculum_map.md`, `control_catalog_usage_guide.md` | Click-automation UI-grounding course |
| `suno-mastering-course-breakdown.md`, `suno-mastering-curriculum.md` | Suno mastering course curriculum |
| `ableton_ai_educational_risk_framework.md` | Escalation-ladder rationale (teaching order) |
| `SESSION_01_ES.md`, `mastering_progress.md` | Session artifacts |
| `KNOWN_ISSUES.md`, `MASTERING_COURSE_KNOWN_ISSUES.md` | Teaching-course friction logs |

`build_mastering_env.sh` still assembles the mastering runtime from these paths
if you want to re-run that course.
